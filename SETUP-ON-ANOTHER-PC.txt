===========================================================
 LESCO Meter Data Analyzer — running it on another PC
===========================================================

The full dashboard (the web app) now runs from a SINGLE
server. Python serves both the analysis and the web pages,
so the other PC does NOT need Node.js.


-----------------------------------------------------------
 WHAT IS IN THIS FOLDER
-----------------------------------------------------------

     backend\       the Python analysis engine
     Frontend\      the dashboard (source + built "dist" folder)
     data\          meter exports used for testing
     docs\          reports, specs, design mockups
     archive\       old zips and superseded output files
     dist\          the old standalone desktop .exe

     RUN-LESCO.bat            <-- run the app (Python only)
     START.bat                <-- development mode (needs Node.js)
     ALLOW-NETWORK-ACCESS.bat <-- run once as admin to share on the network


-----------------------------------------------------------
 WHAT TO COPY
-----------------------------------------------------------

  Copy the "Lesco Claude" folder, but leave out the data
  and the build leftovers.

  COPY THESE:

     backend\                          the analysis engine (~92 KB)
     requirements.txt
     RUN-LESCO.bat                     <-- the one to double-click
     ALLOW-NETWORK-ACCESS.bat          only if others will connect
     SETUP-ON-ANOTHER-PC.txt           this file

     Frontend\lesco-mdm-frontend\dist\     the built dashboard (~1 MB)

  DO NOT COPY (not needed, ~210 MB of clutter):

     data\                                 the meter datasets (~76 MB)
     docs\                                 reports and design files
     archive\                              old zips and superseded outputs
     Frontend\lesco-mdm-frontend\node_modules\      (134 MB)
     Frontend\lesco-mdm-frontend\src\               (source, not needed to run)
     dist\                                 the old desktop .exe
     __pycache__\

  Total to copy: about 1 MB. It fits on any USB stick.

  NOTE: "dist" appears twice and they are different things.
    Frontend\lesco-mdm-frontend\dist   = the built dashboard — COPY THIS
    dist\ (in the main folder)         = the old desktop .exe — skip it


-----------------------------------------------------------
 ONE-TIME SETUP ON THAT PC
-----------------------------------------------------------

  1. Install Python 3.11 or newer
         https://www.python.org/downloads/
         >>> TICK "Add Python to PATH" during install <<<

     This needs admin rights. Ask IT if you do not have them.
     Nothing else needs installing — no Node.js.

  2. Double-click RUN-LESCO.bat

     The first run installs the Python packages automatically
     (needs internet just that once, about a minute).
     Every run after that is offline.


-----------------------------------------------------------
 NO INTERNET ON THAT PC
-----------------------------------------------------------

  The first run needs to download 6 Python packages. If the
  office PC has no internet (or a proxy blocks it), that step
  fails and the app will not start.

  Fix it by carrying the packages on the same USB stick.

  ON A PC THAT DOES HAVE INTERNET (e.g. your laptop), inside
  this folder run:

      pip download -r requirements.txt -d wheels

  That fills a "wheels" folder (~60 MB). Copy it across with
  everything else.

  ON THE OFFICE PC, once, before RUN-LESCO.bat:

      pip install --no-index --find-links wheels -r requirements.txt

  After that RUN-LESCO.bat works normally and never needs
  internet again.

  NOTE: the wheels must match that PC's Python version and be
  64-bit Windows, same as the PC you downloaded them on. If
  both are 64-bit Windows with Python 3.11+, this works.


-----------------------------------------------------------
 USING IT
-----------------------------------------------------------

  Double-click RUN-LESCO.bat. It starts the server and opens
  your browser at:

      http://localhost:8000

  To stop: close the window titled "LESCO Server".

  Everything is on port 8000 — the dashboard and the analysis
  are the same server now.


-----------------------------------------------------------
 IF OTHERS SHOULD ALSO USE IT FROM THEIR OWN PCs
-----------------------------------------------------------

  1. On the PC running it, right-click
         ALLOW-NETWORK-ACCESS.bat
     and choose "Run as administrator". Once only.

  2. RUN-LESCO.bat prints an address like
         http://192.168.1.45:8000
     Share that. Others just open it in their browser.

  The analysis always runs on the host PC, so other people's
  machine speed does not matter.

  IF THEY CANNOT CONNECT: Windows may have the office network
  set as "Public". The firewall rules only cover Private and
  Domain networks. Change it in Settings > Network, or ask IT.


-----------------------------------------------------------
 THINGS WORTH KNOWING
-----------------------------------------------------------

  * Results are held in memory. Closing the server window
    discards them — the analysis has to be run again.

  * Only the 3 most recent analyses are kept. Running a 4th
    releases the oldest to keep memory in check; opening an
    old one then says so and asks you to run it again. Export
    to Excel anything you want to keep.

  * A full month of ~135 meters (a 22 MB Load Profile export)
    takes about 45 seconds and needs roughly 525 MB of RAM at
    peak. An older office PC may take two to three times that.

  * While it runs, the page shows the step it is on
    ("Step 1/6 Reading the Load Profile ..."). If that message
    keeps changing, it is working - just let it finish. The
    same steps are printed in the "LESCO Server" window.

  * The Load Profile file is the slow part - it is far bigger
    than the others. Analysing one month at a time is much
    quicker than several months at once.

  * All data stays on this PC / the office network. Nothing
    is uploaded anywhere.

  * If the analysis code is ever changed, the dashboard must
    be rebuilt (npm run build) on a PC that has Node.js, and
    the new dist folder copied across.


-----------------------------------------------------------
 IF SOMETHING DOES NOT WORK
-----------------------------------------------------------

  "Python was not found"
      -> Python not installed, or "Add Python to PATH" was
         not ticked during install. Reinstall and tick it.

  "The dashboard has not been built"
      -> Frontend\lesco-mdm-frontend\dist was not copied.
         Copy that folder across.

  Page opens but analyses fail
      -> look at the window titled "LESCO Server" for the
         error message.

  Others cannot open the shared address
      -> ALLOW-NETWORK-ACCESS.bat not run as administrator,
         or the network is set to "Public" in Windows.

  Tables are empty after restarting
      -> results live in memory only. Run the analysis again.
